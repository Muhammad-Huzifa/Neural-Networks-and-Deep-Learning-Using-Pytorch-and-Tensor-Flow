# Application launchers

Run from the project root after training:

```bash
python -m pip install -r requirements-apps.txt
python deployment/07_api.py
```

For the local Streamlit interface:

```bash
python -m streamlit run deployment/app.py
```

Both applications load `artifacts/pipeline.joblib`, generated by `python train.py`. They no longer reconstruct dummy variables independently for each prediction. See the [project README](../README.md).
