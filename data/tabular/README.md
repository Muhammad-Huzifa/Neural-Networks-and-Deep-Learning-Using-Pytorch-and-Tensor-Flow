# Tabular data

`diabetes.csv` and `patient_records.csv` are copied from the original repositories without changing their contents. Their original upstream provenance is not recorded in those repositories; this collection does not assign a new dataset license or claim they are benchmark releases.

The following local CSVs must be supplied for the corresponding original experiments: `salary_data.csv`, `titanic_train.csv`, `coffee_roasting.csv`, and `fashion-mnist_train.csv`. See `docs/DATASETS.md` for the affected lessons. No fabricated replacement data is presented as the original dataset.
